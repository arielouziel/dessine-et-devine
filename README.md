# Dessine et Devine

Jeu de dessin à deviner en équipes, pour les enfants (4 à 12 ans). On dessine sur un vrai tableau ; le téléphone choisit le mot, lance le chrono et compte les points.

- 2 à 4 équipes, noms personnalisables
- 3 niveaux de mots (Petits, Moyens, Grands), avec une image d'aide
- Chrono de 60 s, 90 s ou 2 min, objectif de 3, 5 ou 8 mots
- La partie est gardée si on ferme la page

Une seule page, `index.html`, sans dépendance ni étape de build. Publiée avec GitHub Pages.
